# TUI 结构调整：运行独立成页 + 模型页承载「选中模型设置」

## Goal

把 TUI 从「三块常驻 + 四个页」调成「模型页一眼看全当前模型及其开关，运行状态有自己的一页」：

- 右下角常驻的「反馈 / 请求活动」改成**独立的运行页**（守护进程状态 + 重启按钮 + 反馈事件 + 请求活动 + 近 60 秒指标）；
- 模型页右栏腾出来放**选中模型设置**：四个输入过滤开关 + 一行「warp 模式」；
- 独立的「模式」页撤掉 —— 模式搬进模型页的设置块，只换位置，语义不变。

## 背景

- 现在：模型页左栏是模型列表、右栏是「守护进程 + 反馈 / 请求活动」；`模式` 是单独一页；输入过滤开关原本要藏在模型页的 `e` 弹出层里。
- 用户要求：开关要和模型选择在同一屏（一眼可见、不用记键）；运行状态要看详细内容，就该单独一页，而不是永远挤在右下的四行里。
- 现状约束：右栏同时放守护进程、反馈、活动、指标，24 行终端下活动只剩 1–2 条，本来就不够看。

## Requirements

- **L1 导航**：`模型` / `供应商` / `统计` / `运行` 四页（`模式` 页撤掉）。`←→` 在导航栏上仍然循环切页。
- **L2 运行页**：整页展示
  - 守护进程状态（状态 / 供应商 / 模型 / 版本 / 接入地址 / 启动时间 / 配置文件）与重启按钮；
  - 反馈事件列表（`✓` / `✗` / `!`，含失败原因，刷新不清空）；
  - 请求活动列表（近 60 秒窗口，含 `img×2 aud×1`、`rsn medium→high` 这类改写摘要）；
  - 近 60 秒指标（`近60秒 请求 N · 错误 N`、`平均耗时 Nms`、`本次运行 请求 N · 错误 N`）。
  内容多于屏幕高度时按优先级截断（重启按钮与指标永远可见），并说明隐藏了多少条。
- **L3 模型页**：左栏 = 模型列表，右栏 = 选中模型的设置块，含
  - 四个输入过滤开关（图片 / 音频 / 文件 / 视频）——**内容由 `10-18-input-media-filter` 提供**，本任务只提供容器与焦点；
  - 一行「warp 模式」：`按客户端请求` / `统一用当前模型`，`Enter` 打开确认后写 `useClientModel` 并 reload（与现在的模式页语义一致）。
- **L4 模式语义不变**：仍是**全局**开关（`useClientModel`），不是按模型的；「按模型配置模式」不在本次范围。
- **L5 键盘**：模型页 `←→` 在「模型列表 ↔ 设置块」之间移动焦点；设置块里 `↑↓` 选行、`Enter` 改（过滤行 = 切换开关，模式行 = 进确认）；运行页 `←→` 在「页内容 ↔ 守护进程 / 重启按钮」之间移动；页脚与键位表同步。
- **L6 运行页只读**：唯一可写动作是重启 daemon（确认流不变：`Enter` 进确认、`Esc` 取消）。
- **L7 统计页不受影响**：`h` 切统计范围、目标表、口径说明保持原样。
- **L8 兼容**：`llmwarp tui` 之外的行为（CLI、daemon、admin API、配置格式）一个字节不改。

## Non-goals

- 不做「按模型配置模式」（那是新需求）。
- 不做日志落盘 / 分页 / 搜索：运行页展示的仍是内存里的实时窗口（近 60 秒 + 本次运行累计），历史数据仍在 `统计` 页。
- 不改统计口径、不改 `/v1` 行为、不加 CLI 子命令。

## Acceptance Criteria

- [x] 导航只有 `模型` / `供应商` / `统计` / `运行` 四页，`模式` 页不再存在。
- [x] 运行页能看到：守护进程状态、重启按钮、反馈事件、请求活动、近 60 秒指标；24 行终端下重启按钮与指标仍可见，被截断的条数有提示。
- [x] 反馈事件（`✓ 已启动 daemon` / `✗ 切换模型失败：…`）在运行页可见，且不被自动刷新清掉。
- [x] 请求活动里的过滤摘要（`img×2 aud×1`）与思考强度摘要（`rsn medium→high`）在运行页可见。
- [x] 模型页右栏显示「选中模型设置」块与其中的「warp 模式」一行（四行过滤开关由 `10-18-input-media-filter` 追加）；`←→` 能在列表与设置块之间移动，`↑↓` 在设置块内选行，`Enter` 生效。
- [x] 在模型页改「warp 模式」写 `useClientModel` 并 reload，行为与旧模式页一致（含确认文案：切换为「统一用当前模型」时客户端模型名会被忽略）。
- [x] 重启 daemon 仍需确认，位置在运行页；确认期间 `q` / `r` / 方向键被忽略（沿用现有确认态语义）。
- [x] 窄 / 矮终端（72 列、12 / 16 / 24 行）下整帧不越界、不滚屏（每行补齐到 width、行数不超 height）。
- [x] `.trellis/spec/frontend/interaction-guidelines.md` 与两个 README 的键位 / 页面说明同步。
- [x] `npm run typecheck`、`npm test`、`npm run build` 全绿。
