# 统计页时效性改造

## Goal

统计页支持按时间窗（月/周/日/小时或最近请求）查看，新增最近 tok/s 拥堵判断，并让火花线可读（具体数值）。

## 背景

- 现有聚合（`src/stats/aggregate.ts`）只有：整体 `overall`、按天 `days`、按小时 `hours`（稀疏，仅保留期内）、按上游目标 `targets`（跨保留期汇总）与 `unrouted`。
- 目标表是保留期内全期汇总，没有时间维度；火花线按天或「最近 24 个活跃小时」画，没有刻度也没有数值，用户只能看出形状、看不出具体多少。
- 「这个模型现在挤不挤」需要比全期平均更近的窗口（tok/s、RPM），现有视图给不出。

## 需求

- 统计页提供窗口选择器（`h` 循环，共 5 个，顺序固定）：`最近10条 / 近1小时 / 今天 / 近7天 / 近30天`；只保留一个「最近 N 条」= 10 条。
- 窗口作用于**数字**：汇总行与上游行表格的 请求数 / 错误率 / 平均 / TTFT / tok/s 都按选中窗口重算。
- **窗口与火花线解耦**：火花线固定显示最近 30 天按天的 token 趋势，并标 `最小 / 最大 / 当前`。
- 长请求不丢：`最近10条` 不按时间过滤；`近1小时` 按完成时刻计入；进行中请求不显示（与现状一致）。
- 保留「统计页只读、不改配置、不写统计文件、除 `h` 外不新增单字母动作键」的约束。

## 非目标

- 不改 `/v1` 转发行为与 JSONL 事件字段（除非设计确认必需）。
- 不做限流 / 配额面板。
- 不改 `/v1/models` 与路由语义。

## 验收标准

- [ ] 可切换 5 个窗口，汇总与上游行表格随窗口重算。
- [ ] 每个上游行可见窗口内的 tok/s（及请求数 / 错误率 / 平均 / TTFT）。
- [ ] 火花线固定显示最近 30 天 token 趋势，并标 最小 / 最大 / 当前。
- [ ] 统计页仍为只读；自动刷新不重置窗口 / 选中等视图状态。
- [ ] `npm run typecheck`、`npm test`、`npm run build` 通过。
- [ ] README 统计页说明同步。
