# 统计页口径与 TUI 提示语可读性

## 背景

用户连续反馈「统计页看不懂」，逐条定位到的问题都不是数据算错，而是**页面没把话说清楚**：

1. 表格列名 `平均` / `TTFT` / `tok/s` 不知道统计的是什么、单位是什么、算的是哪些请求。
2. 页面上没有任何地方说明**统计口径**：哪些请求计入、哪些不计入。
3. 统计页底部「选中详情」显示的是**选中上游**的指标，和表格那一行重复；用户要看的是**总体汇总**。
4. TUI 底部快捷键提示用词不一致（`换页` / `换区`、`↑↓ 选中` / `↑↓ 选择` / `↑↓ 选择目标`），含义要靠猜。
5. 模型页在「暂无模型」空态下仍然提示 `Enter 确认`，而空列表时 Enter 什么都不发生（死提示）。

### 后续修订（用户第二轮反馈，覆盖上文）

1. **「窗口」照样看不懂** → 改为「统计范围」。`最近10条` 是条数、其余是时间，用一个「窗口」罩住两种口径自相矛盾；「范围」能同时涵盖两种。
2. **`平均` 和 `平均耗时` 都不合格** → `平均` 没说统计什么；`平均耗时` 没说是什么耗时。而更重要的是**总耗时（端到端）本身没价值**：它被回答长度主导，输出 2000 token 天然比 200 token 慢数倍，拿来横比上游会误导（代码里早就有同样判断——`p95` 因此被移出表格）。
   → **从目标表删掉这一列**；改名后的 `平均总耗时` 只留在「当前统计范围总计」里（那里它表示「我平均等了多久」，有意义）。
3. 「统计范围总计」的标题随之从 `当前统计范围总计` 改为 `当前统计范围总计`。

## 现状口径（代码事实，改文案必须与之一致）

来自 `src/stats/aggregate.ts` 的 `addToBucket` / `metricsOf`：

- `requests`：每一条**已结束**的转发请求（含上游返回错误的），进行中的不计。
- 路由失败（`routeKind === "unrouted"`）：完全不进 `overall` / `targets`，单独计数为「未发出」。
- 客户端取消（`termination === "client_aborted"`）：计入 `requests` 与 `中断`，**不计入** `errors`，也**不进**耗时统计（avg / p50 / p95）。
- `errorRate` 分母 = `requests - aborted`。
- `总耗时`（现 `平均` / `avgDurationMs`）：只对非取消请求求平均，从发出请求到收完整响应。
- `首字延迟`（现 `TTFT`）：只统计拿到 `ttftMs` 的请求（流式才有）；非流式无样本。
- `输出速度`（现 `tok/s`）：只统计「流式 + 有 TTFT + 未被取消」的样本 = 输出 token ÷ (总耗时 − 首字延迟)；无样本显示 `—`。
- token 四项：上游返回的 usage 汇总。

## 改动清单（含具体文案）

### 1. 统计页列名与汇总行用词

| 位置 | 现在 | 改成 |
|---|---|---|
| 目标表表头 | `平均` | **删除该列**（端到端耗时被回答长度主导，横比上游会误导） |
| 目标表表头 | `TTFT` | `首字延迟` |
| 目标表表头 | `tok/s` | `输出速度` |
| 当前统计范围总计 | `总耗时` | `平均总耗时`（保留，表示「我平均等了多久」） |

目标表列固定为 `供应商/模型 · [端点] · 请求 · 错误率 · 首字延迟 · 输出速度`。`labelWidth >= 8`，窄终端优先保住数值列；`showEndpoint` 阈值按新列宽相应下调（`width - 50 >= 20`）。

### 2. 统计页新增口径说明（灰色 dim，放在目标表下方）

两行，每行在 72 列终端下**不得被截断**（渲染时由 `truncate` 兜底，但文案本身要短）：

```
口径  已结束的转发请求；进行中、路由失败不计；中断只计请求数，不计错误与耗时
列义  表内数值 = 各上游在当前统计范围的样本平均；首字延迟 = 第一个 token 到达（仅流式）；输出速度 = 输出token÷解码时间，单位 tok/s（仅流式）
```

（72 列下仍超宽，按 `；` 折行成多物理行，不截断。）

### 3. 统计页详情区改为「当前统计范围总计」

- 删掉顶部那 3 行 `汇总 …`（其字段全部被下面的总计块覆盖，避免重复）。
- 把原「选中详情」改成「当前统计范围总计」，数据源从选中上游改为当前统计范围的 `overall`（`statsWindowData(state).overall`），字段沿用原详情的 5 行：延迟（平均总耗时/50分位/95分位）、首字延迟（平均/95分位/样本）、吞吐（输出速度/流式/非流式）、token（输入/输出/总/缓存/推理）、可靠性（请求/错误/错误率/中断/截断/拦截）。
- 因为详情不再跟随选中，统计页**去掉选中态**：不再渲染行高亮，页脚去掉 `↑↓`，`statsSelected` 相关的选中/重定位逻辑若因此变成死代码则一并清理（`restoreStatsView` 只保留 `statsWindow`）。
- 目标表保留，只做上游之间的横向对比。

### 4. TUI 底部快捷键提示统一措辞

- 导航栏提示：`←→ 换页  ↑↓ 进入列表` → `←→ 切页面  ↑↓ 进入列表`
- 模型 / 模式页：`↑↓ 选中  ←→ 换区/换页  Enter 确认  Esc 取消  r 刷新  q 退出`
  → `↑↓ 选择 · Enter 切换 · ←→ 切页面/左右栏 · Esc 返回 · r 刷新 · q 退出`
- 供应商页：`↑↓ 选中  Enter 打开操作菜单  ←→ 换页  r 刷新  q 退出`
  → `↑↓ 选择 · Enter 操作菜单 · ←→ 切页面/左右栏 · Esc 返回 · r 刷新 · q 退出`
- 统计页：`↑↓ 选择目标  h 窗口  ←→ 换页  r 刷新  q 退出`
  → `h 切换统计范围 · ←→ 切页面/左右栏 · r 刷新 · q 退出`
- 模式页正文内嵌：`Enter 切换模式  ←→ 换区` → `Enter 切换模式  ←→ 切页面/左右栏`
- 确认框内保留现有 `Enter 确认  Esc 取消` 措辞（已经清楚）。
- **不再出现 `换页` / `换区` 两个词**；所有页脚统一以 `·` 分隔、`Esc 返回` 必须出现（统计页无 Esc 行为则不加）。

### 5. 模型页空态死提示

- 现有：`暂无模型，请先运行 llmwarp add` + `Enter 确认  q 退出`
- 改为：`暂无模型，请先运行 llmwarp add` + `q 退出`（空列表下 Enter 无任何行为，不得再提示）。

### 6. 「窗口」措辞

- **不保留「窗口」**（见上文修订）。统计页顶部行改为 `统计范围 {label} · 只算已结束的转发请求`（去掉原 `已完成请求 · 进行中不计`，该信息移入口径说明）。
- 旧 daemon 降级行同步为 `统计范围 全期（旧版 daemon 未提供范围数据）`。
- 页脚 `h 切换统计窗口` → `h 切换统计范围`。

### 7. 文档同步

- `README.md` 统计页段落按新列名 / 口径 / 总计区改写；TUI 按键段按新提示语改写。
- `.trellis/spec/backend/usage-stats.md`：列名-出口矩阵、出口规则、测试契约中的 `平均` / `TTFT` / `tok/s` 术语同步。
- `.trellis/spec/frontend/interaction-guidelines.md`：按键表与统计页描述同步（含「统计页无选中态」）。

## 验收标准

- [ ] 目标表不再出现 `平均` / `TTFT` / `tok/s` / `总耗时`；表头为 `请求 · 错误率 · 首字延迟 · 输出速度`。
- [ ] 目标表**没有**总耗时列；`平均总耗时` 只出现在「当前统计范围总计」。
- [ ] 统计页不再出现「窗口」字样（`统计范围` 取代）；`窗口内暂无已完成请求` → `范围内暂无已完成请求`。
- [ ] 统计页能看到两条口径说明（`口径` / `列义`），且 72 列宽终端下不被截断。
- [ ] 统计页详情区标题为「当前统计范围总计」，数据来自当前窗口 `overall`，含延迟分位 / 首字延迟分位 / 吞吐 / token 四项 / 可靠性完整字段。
- [ ] 统计页不再有选中高亮，页脚不再出现 `↑↓`；`h` 仍循环 5 个统计范围且行为不变。
- [ ] 全 TUI 不再出现 `换页` / `换区` 字样；模型页空态不再出现 `Enter 确认`。
- [ ] 渲染不变量保持：每行补齐到 `width`、末行 `width-1`、不超 `height`（现有测试必须继续通过）。
- [ ] `npm run typecheck` / `npm test` / `npm run build` 全绿。
- [ ] 版本号不变（仍 `1.2.0`）。

## 非目标

- 不改任何统计计算逻辑、聚合口径、持久化格式。
- 不改 `dist` 打包、不做 npm 发布相关改动。
- 不新增按键（除现有 `h` / `r` / `q` / `Esc` / `←→` / `↑↓` / `Enter`）。
- 不改供应商页操作菜单、模型页/模式页的切换行为；`TuiPage` / `ConfirmIntent` 等内部标识符不动。

## 设计取舍

- 顶部 3 行 `汇总` 与底部总计块字段高度重合，二选一：保留底部总计块（字段更全），删顶部 3 行。避免同一屏两处重复数字。
- 详情不再跟随选中 ⇒ 选中态失去意义 ⇒ 一并去掉，而不是留一个没有作用的行高亮（那正是用户抱怨的「看不懂」来源）。
